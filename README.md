## 🧠 About This Project

A hands-on cybersecurity AI laboratory exploring two approaches to AI-assisted cybersecurity learning:

### 🧠 Module 01 — Local LLM

Deployment and evaluation of an 8B cybersecurity-focused Large Language Model using Ollama.

### 🤖 Module 02 — Cybersecurity AI Agent

Building an AI learning agent using OpenClaw, an LLM backend, Telegram and web-search capabilities.
