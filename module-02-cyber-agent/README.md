# 🤖 Module 02 — Cybersecurity AI Learning Agent

## Overview

This module explores the deployment of an AI agent designed to assist with cybersecurity learning and research.

The agent was built using OpenClaw with an LLM backend, Telegram as the communication interface and web-search capabilities.
